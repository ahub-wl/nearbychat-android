# NearbyChat

Private, offline, peer-to-peer messaging for Android.

NearbyChat is designed for direct communication between nearby Android devices without cloud messaging servers.

## v1.0.0

The first stable release of NearbyChat.

### Download

Download the APK from the [v1.0.0 GitHub Release](../../releases/tag/v1.0.0).

### Requirements

- Android 7.0 (API 24) or higher
- Nearby devices with Bluetooth/Wi-Fi capabilities

### Privacy

NearbyChat is designed for direct nearby communication and does not use cloud chat servers for message delivery.
